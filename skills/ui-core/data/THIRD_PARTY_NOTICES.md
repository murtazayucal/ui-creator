## Registry catalog

`registries.json` is generated by `tools/build-registries.mjs` from the public shadcn registry index at `https://ui.shadcn.com/r/registries.json` (shadcn/ui, MIT). It keeps each registry's name, homepage, description, item count and health status, and adds this project's own categories and "featured" flag. Descriptions are written by each registry's author. The license of the index file itself was not checked separately from the shadcn/ui repository.

## Changes made to the source data

- Color values were converted to hex and OKLCH. Colors outside sRGB were brought into gamut by reducing chroma.
- Role names were mapped to one vocabulary (`background`, `foreground`, `card`, `primary`, `onPrimary`, ...). Roles a source does not define are absent.
- daisyUI: `base-100`, `base-200`, `base-300` and `error` were mapped to `background`, `card`/`muted`, `border` and `destructive`.
- Catppuccin: the 26 named colors were assigned to UI roles by this project (`primary` = mauve, `secondary` = blue, `accent` = peach). Catppuccin does not define these roles.
- tweakcn: only the color roles listed above were kept; fonts, radius, shadows, chart and sidebar tokens were dropped.
- WCAG contrast results and hue/chroma tags were computed and added by this project.
